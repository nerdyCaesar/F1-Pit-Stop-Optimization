# F1 Pit Stop Optimization Model
This is a Machine Learning project that uses decision trees to predict if an F1 driver should make a pit stop or not. The project processes raw Jolpica F1 CSV data, creates race strategy features, trains a decision tree classifier, and evaluates predictions using race based cross-validation.


Master Dataset: `f1_lap_data_master.csv` -> Contains the complete processed dataset.

Training Dataset: `f1_lap_data.csv` -> Contains only model-related columns.
